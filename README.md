# NightLapse (найтлапс + Кадр дня)

Одно приложение для iPhone с двумя режимами. Сборка без Mac через GitHub, установка с Windows через Sideloadly.

Переключение режимов: в NightLapse кнопка «Кадр дня» рядом с «Тест» (видна, пока съёмка не идёт), в «Кадре дня» кнопка «Найтлапс» справа вверху. Приложение запоминает последний режим.

- **NightLapse** - найтлапс с длинной выдержкой (каждый кадр = склейка подкадров сенсора).
- **Кадр дня** - один и тот же вид каждый день: на экране виден прозрачный прошлый кадр, а видео собирается с автовыравниванием.

## 1. Загрузить проект на GitHub

1. Зарегистрироваться на github.com (бесплатно).
2. Справа вверху «+» → New repository. Имя: NightLapse. Можно Private. Create repository.
3. Нажать «uploading an existing file» и перетащить из распакованного архива:
   - папки `NightLapse` и `DailyFrame`
   - файлы `project.yml` и `README.md`

   Нажать Commit changes.
4. Папку `.github` Windows и браузер часто не загружают, поэтому файл сборки создаём вручную:
   Add file → Create new file. В поле имени написать ровно:
   `.github/workflows/build.yml`
   Вставить всё содержимое файла `build.yml` из архива. Commit changes.

Если репозиторий уже есть, замени в нём файлы из архива и добавь папку `DailyFrame`.

## 2. Скачать готовые приложения

1. Вкладка Actions. Сборка запустится сама (7-12 минут).
2. Когда она закончится, открой её. Внизу в разделе Artifacts скачай `ipa`.
3. Распакуй zip: внутри `NightLapse.ipa`.

Красный крестик значит, что сборка не удалась. Текст ошибок виден на странице сборки в блоке «Ошибки сборки». Скопируй его и пришли мне.

## 3. Установить на iPhone с Windows

1. Установить iTunes и iCloud с сайта apple.com (не из Microsoft Store).
2. Скачать и установить Sideloadly с sideloadly.io.
3. Подключить iPhone кабелем, на телефоне нажать «Доверять этому компьютеру».
4. В Sideloadly перетащить `.ipa`, ввести свой Apple ID, нажать Start. Пароль Apple ID вводится только в самой программе. 
5. На iPhone: Настройки → Конфиденциальность и безопасность → Режим разработчика → включить (телефон перезагрузится).
6. Настройки → Основные → VPN и управление устройством → свой Apple ID → Доверять.

С бесплатным Apple ID приложения работают 7 дней,  Потом снова шаг 4 с тем же файлом. **Ставь поверх, не удаляя старое приложение**: так сохранятся настройки и кадры «Кадра дня».

## NightLapse: как снимать

1. Штатив, авиарежим, пауэрбанк. На ночь включи «Не беспокоить» (Фокус), чтобы звонки и уведомления не мешали.
2. Объектив: 0.5x для звёзд и широкого неба, 1x для города, Теле для луны и дальних огней.
3. Фокус: вручную на бесконечность (для звёзд) или «Автофокус»: коснись картинки в нужном месте, фокус наведётся один раз и зафиксируется.
4. Выдержка кадра 30 с, пауза 2 с (или как нужно).
5. ISO:
   - «Авто ISO»: приложение само подбирает ISO. В начале оно быстро подстраивается за несколько шагов, дальше меняет ISO плавно, не больше трети ступени за кадр. Подходит для заката и рассвета. Ползунок «Коррекция» делает кадр темнее или ярче (для ночи около -2 EV).
   - Ручной ISO: ставишь сам. Для ровного ночного таймлапса без мерцания обычно лучше.
6. Баланс белого: «Авто» или вручную в кельвинах. В авто цвет может слегка мерцать между кадрами.
7. Нажми «Тест»: приложение снимет один кадр и покажет его. В авто ISO оно сначала подберёт ISO (значение видно в настройках).
8. Режим «Среднее» - меньше шума, для города, облаков и воды. «Треки» - шлейфы огней и звёзд.
9. По желанию: задержка старта (успеть уйти из кадра) и автостоп (чтобы не разрядить телефон за ночь).
10. «Старт», потом кнопка с луной: экран гаснет, съёмка идёт. Коснись экрана, чтобы вернуться.
11. «Стоп»: видео сохранится в «Фото».

### Звонки и сворачивание

iOS не даёт камере работать в фоне. Поэтому если ты принял звонок или свернул приложение, съёмка встаёт на паузу. В видео в этом месте будет скачок (время разговора в ролик не попадёт). Когда приложение снова на экране, съёмка продолжается сама. Всё остаётся одним видеофайлом. Если после звонка телефон показал домашний экран, просто открой NightLapse. Счётчик «пауз» в строке состояния показывает, сколько раз это случилось.

### Важно

- Предпросмотр показывает ровно то, что запишется в видео. По умолчанию видео горизонтальное. Для вертикального включи переключатель до старта.
- «Кадры JPEG в Файлы»: каждый кадр сохраняется отдельно (Файлы → На iPhone → NightLapse). Удобно для обработки на компьютере (LRTimelapse, Lightroom, DaVinci).
- Настройки запоминаются между запусками.
- Вверху видно время съёмки, кадры, длину готового видео, заряд и свободное место. Если телефон перегреется, появится предупреждение.

## Кадр дня: как пользоваться

Идея: каждый день снимать один и тот же вид (окно, стройка, дерево, город) и потом собрать из кадров видео.

**Первый день.** Поставь телефон на штатив или закрепи в одном месте, отметь это место. Выбери объектив и сними первый кадр. Он станет эталоном.

**Каждый следующий день:**
1. Поставь телефон на то же место.
2. Включи «Призрак»: поверх живой картинки появится прозрачный прошлый кадр. Двигай телефон, пока два изображения не совпадут. Ползунок «Прозрачность» меняет яркость призрака.
3. «Контур» показывает не картинку, а красные линии контуров прошлого кадра. Совместить линии часто проще, чем призрак, особенно если погода или свет отличаются.
4. «Откуда»: «Предыдущий» подсказывает по вчерашнему кадру, «Эталон» по первому. Эталон лучше, если снимаешь месяцами: ошибка не копится от кадра к кадру.
5. Вверху видны два числа: «Наклон» и «Курс». Это разница положения телефона с тем моментом, когда снят выбранный кадр, в градусах. Зелёный цвет значит почти идеально. Это датчики телефона (компас иногда сбивается рядом с металлом, тогда ориентируйся на призрак).
6. Сетка и «Фокус ∞» помогают (фокус на бесконечность не прыгает от дня к дню).
7. Нажми белую кнопку. Кадр сохранится в приложении и (по умолчанию) копией в Фото.

**Вкладка «Архив».** Все кадры, звёздочка отмечает эталон. Удерживай кадр, чтобы сделать его эталоном или удалить.

**Сборка видео.** Выбери скорость (например 8 кадров в секунду) и нажми «Собрать видео». «Выровнять кадры автоматически» находит сдвиг каждого кадра относительно эталона и подгоняет его. Лёгкий поворот и разный масштаб оно не исправляет. «Дата в углу» подписывает каждый кадр. Видео сохраняется в Фото. Пока идёт сборка, не закрывай приложение.

**Напоминание.** Включи «Напоминать каждый день» и выбери время. Телефон спросит разрешение на уведомления.

**Проекты.** Если следишь за несколькими местами, создай проект на вкладке «Съёмка» (значок папки). Кадры каждого проекта лежат отдельно.

**Где лежат файлы.** Файлы → На iPhone → NightLapse → папка DailyFrame. Если удалить приложение, кадры оттуда пропадут. Копии в Фото остаются.
